## 更新する前

1. 同じiPhoneの同じSafari・Userscriptsを使い、補助ツールの巡回を一時停止します。現在の版、昼枠／夜枠、端末件数、取得未確認台帳、あとで見る、秒数・目標・自動設定を控えます。公式連動の合計と端末件数は分けて控えます。
2. 既存スクリプトの**実際のファイル名**を確認します。標準は `SR Mission Runner Mobile.user.js`、`@name` は `SR Mission Runner Mobile`、`@namespace` は `https://nao.qa/`。この名前・保存先を保ちます。
3. 自分の操作で複数のSHOWROOMタブを同時に巡回させないようにします。録画・数値収集など別の仕組みを止める必要はありません。

## 同名へ上書きする

1. 上の固定URLをSafariで開きます。コードの表示だけではインストールされません。
2. Safariのページメニュー → 拡張機能 → Userscripts → **Tap to re-install** → **Install**。既存の同名スクリプトへ上書きします。
3. re-installにならず、新規インストール・別名ファイルの追加になる場合は、そのまま追加しません。既存の実際のファイル名・保存先を維持し、内容だけ置き換えます。新旧2本を同時に有効化しないでください。
4. Userscriptsを開いて読み込み完了を待ち、SHOWROOMタブを再読み込みします。パネルを戻して **v1.6.8** を確認します。
5. 同じ時間枠の件数・台帳・設定を更新前と照合します。`@name`、`@namespace`、`srmr_progress_v3`および履歴・台帳の保存キーは変更していません。ただし、利用中のiPhoneアプリ内部での保存引継ぎは実機受入が必要です。

**更新で行わないこと:** 件数リセット、スクリプト削除、Userscriptsの削除・再インストール、ファイル名／保存先変更、Safariや拡張のデータ消去。スクリプトファイルのコピーはコードの控えであり、進捗データのバックアップではありません。

日本時間03:00／15:00をまたぐと新しい枠の件数になります。枠切替を履歴消失と誤判定しないでください。

保存単位の根拠と既存の詳細手順は [v1.6.6手順の「保持を確認した範囲」](SR-MISSION-RUNNER-166-TRIAL.md#保持を確認した範囲) を参照。現行iPhone上で同名上書きに成功したという証拠へ読み替えません。

## エラーが出たら

1. v1.6.8で `-2002` と「エラー中・保留」を表示するか確認します。パネル退避中も「保存して配信を再読込」「記録せず次へ」が見えることを確認します。
2. 「保存して配信を再読込」は保存成功後だけ1回再読み込みします。保存できない場合はページを移動しません。エラーの連続自動再試行はしません。
3. 同じエラーが続く場合は「記録せず次へ」を1回押します。次の候補へ進み、端末の完了件数・取得確認台帳・除外履歴を増やさないことを確認します。候補切れでは一覧に戻って停止します。
4. 複数の配信で同じエラーが続く場合は自動OFFにし、通常の公式ルーム `/r/{slug}` を別タブで開いて、補助なしでも再生できるか確認します。設定変更やデータ消去を繰り返さず、通常ルーム／liteのどちらで起きるかを切り分けます。公式画面でも再生不能なら、ツールのスキップ処理だけでは映像を復旧できません。
5. 正常な配信で本人の再生操作後にカウントが進むことを確認します。公式ミッション回数・受取は公式画面で確認し、端末記録から成功を推定しません。
